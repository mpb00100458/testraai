## 🛠️ **Technical Implementation Roadmap**

### **Phase 1: Multi-Tenancy & Authentication (Weeks 1-2)**

**Database Schema Changes:**
```sql
-- Organizations table
CREATE TABLE organizations (
  id UUID PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  plan VARCHAR(50) NOT NULL, -- starter, professional, business, enterprise
  max_scans_per_month INTEGER,
  max_users INTEGER,
  created_at TIMESTAMP DEFAULT NOW(),
  stripe_customer_id VARCHAR(255),
  stripe_subscription_id VARCHAR(255)
);

-- Users table (extend existing)
ALTER TABLE users ADD COLUMN organization_id UUID REFERENCES organizations(id);
ALTER TABLE users ADD COLUMN role VARCHAR(50); -- admin, member, viewer

-- Scans table (extend existing)
ALTER TABLE scans ADD COLUMN organization_id UUID REFERENCES organizations(id);

-- Usage tracking
CREATE TABLE usage_metrics (
  id UUID PRIMARY KEY,
  organization_id UUID REFERENCES organizations(id),
  month DATE NOT NULL,
  scans_used INTEGER DEFAULT 0,
  api_calls INTEGER DEFAULT 0,
  storage_used_mb INTEGER DEFAULT 0
);

-- API keys
CREATE TABLE api_keys (
  id UUID PRIMARY KEY,
  organization_id UUID REFERENCES organizations(id),
  key_hash VARCHAR(255) NOT NULL,
  name VARCHAR(255),
  last_used_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT NOW(),
  expires_at TIMESTAMP
);
```

### **Phase 4: CI/CD Integrations (Weeks 9-10)**

**GitHub Actions:**
```yaml
# .github/workflows/accessibility-scan.yml
name: Accessibility Scan
on: [push, pull_request]
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - uses: testraai/accessibility-scan-action@v1
        with:
          api-key: ${{ secrets.TESTRAAI_API_KEY }}
          url: https://preview-${{ github.sha }}.example.com
          wcag-level: AA
          fail-on: critical,serious
```

**GitLab CI/CD:**
```yaml
# .gitlab-ci.yml
accessibility-scan:
  stage: test
  script:
    - curl -X POST https://api.testraai.com/v1/scans \
      -H "Authorization: Bearer $TESTRAAI_API_KEY" \
      -d '{"url":"https://preview.example.com","wcagLevel":"AA"}'
```
