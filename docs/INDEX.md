## 🚀 Getting Started

### 1. Choose Your Path
- **New to project?** → Start with [LIVE_TESTING_README.md](./LIVE_TESTING_README.md)
- **Frontend dev?** → Go to [LIVE_TESTING_UI_COMPONENTS.md](./LIVE_TESTING_UI_COMPONENTS.md)
- **Backend dev?** → Check [LIVE_TESTING_IMPLEMENTATION.md](./LIVE_TESTING_IMPLEMENTATION.md#backend-implementation)
- **Need quick answer?** → Use [LIVE_TESTING_QUICK_REFERENCE.md](./LIVE_TESTING_QUICK_REFERENCE.md)

### 2. Explore the Code
```bash
# Frontend
client/src/components/LiveTestingPanel.tsx
client/src/pages/AIAgent.tsx

# Backend
server/websocket.ts
server/agents/realScanAgent.ts
server/routes.ts
server/ai-agent.ts
```

### 3. Run the Application
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test
```
